# 🩺 HealthifyAI

**HealthifyAI** is an intelligent **medical chatbot** designed to provide reliable and conversational health-related assistance.  
Powered by **Large Language Models (LLMs)** and advanced **retrieval-augmented generation (RAG)** using **LangChain** and **Pinecone**, it delivers accurate and context-aware medical responses.

---

## 🚀 Project Description

HealthifyAI integrates **AI-driven natural language processing** with **retrieval-based search** to simulate human-like conversations about medical topics.  
It assists users with general health questions, lifestyle tips, and symptom-related insights — all backed by a curated dataset and embeddings for improved accuracy.

The backend is deployed on **AWS** for scalability and reliability, while **Flask** handles real-time user interaction.
